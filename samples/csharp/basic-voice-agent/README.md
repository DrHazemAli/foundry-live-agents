# Basic Voice Agent (C#)

This is a basic example demonstrating real-time voice conversation with Azure Speech Voice Live API in C#.

## Features

- Real-time voice conversation
- WebSocket connection management
- Audio streaming
- Text transcription
- Error handling

## Prerequisites

- .NET 8.0 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Restore dependencies:
```bash
dotnet restore
```

2. Create `appsettings.json` file and run:
```bash
dotnet run
```
