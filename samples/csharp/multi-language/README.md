# Multi-Language Sample (C#)

This sample demonstrates multi-lingual voice conversations with automatic language detection and voice switching using Azure Speech Voice Live API in C#.

## Features

- Automatic language detection (12 languages)
- Dynamic voice selection
- Real-time voice switching
- Multilingual VAD support
- Regex-based detection

## Prerequisites

- .NET 8.0 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

```bash
dotnet restore
dotnet run
```
