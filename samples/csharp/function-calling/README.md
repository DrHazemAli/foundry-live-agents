# Function Calling Sample (C#)

This sample demonstrates function calling capabilities with Azure Speech Voice Live API in C#.

## Features

- Custom functions with JSON Schema
- Automatic function execution
- Return results to conversation
- Multiple function types
- Type-safe implementation

## Prerequisites

- .NET 8.0 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

```bash
dotnet restore
dotnet run
```
