# VoiceRAG Pattern Sample (C#)

Voice + Retrieval-Augmented Generation pattern with Azure Speech Voice Live API in C#.

## Features

- Knowledge base integration (6 documents)
- Document retrieval with scoring
- Function calling for search
- Streaming responses with citations

## Prerequisites

- .NET 8.0 or later
- Azure Speech Services resource

## Setup

```bash
dotnet restore
dotnet run
```
