# Streaming Responses Sample (Python)

This sample demonstrates advanced streaming techniques with Azure Speech Voice Live API in Python, including partial responses, delta handling, and real-time output processing.

## Features

- Delta streaming for text and audio
- Partial response handling
- Real-time output processing
- Buffering strategies
- Progress indication

## Prerequisites

- Python 3.8 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Create `.env` file and run:
```bash
python main.py
```
