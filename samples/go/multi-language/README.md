# Multi-Language Sample (Go)

This sample demonstrates multi-lingual voice conversations with automatic language detection and voice switching using Azure Speech Voice Live API in Go.

## Features

- Automatic language detection
- Dynamic voice selection
- Support for 12 languages
- Real-time voice switching
- Multilingual VAD

## Prerequisites

- Go 1.21 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
go mod download
```

2. Create `.env` file and run:
```bash
go run main.go
```
