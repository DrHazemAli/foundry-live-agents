# Basic Voice Agent (Go)

This is a basic example demonstrating real-time voice conversation with Azure Speech Voice Live API in Go.

## Features

- Real-time voice conversation
- WebSocket connection management
- Audio streaming
- Text transcription
- Error handling

## Prerequisites

- Go 1.21 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
go mod download
```

2. Create `.env` file and run:
```bash
go run main.go
```
