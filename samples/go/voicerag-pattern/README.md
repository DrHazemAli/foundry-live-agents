# VoiceRAG Pattern Sample (Go)

This sample demonstrates the Voice + Retrieval-Augmented Generation pattern with Azure Speech Voice Live API in Go.

## Features

- Knowledge base integration
- Document retrieval
- Function calling for search
- Streaming responses with citations
- Real-time information augmentation

## Prerequisites

- Go 1.21 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
go mod download
```

2. Create `.env` file and run:
```bash
go run main.go
```
