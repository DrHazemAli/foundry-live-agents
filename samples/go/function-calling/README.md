# Function Calling Sample (Go)

This sample demonstrates function calling capabilities with Azure Speech Voice Live API in Go.

## Features

- Define custom functions with JSON Schema
- Automatic function execution
- Return results to conversation
- Multiple function types
- Error handling

## Prerequisites

- Go 1.21 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
go mod download
```

2. Create `.env` file and run:
```bash
go run main.go
```
