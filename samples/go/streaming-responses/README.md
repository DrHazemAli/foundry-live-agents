# Streaming Responses Sample (Go)

This sample demonstrates advanced streaming techniques with Azure Speech Voice Live API in Go.

## Features

- Real-time delta streaming
- Text buffering strategies
- Partial response handling
- Performance metrics
- Progress indication

## Prerequisites

- Go 1.21 or later
- Azure Speech Services resource with Voice Live enabled

## Setup

1. Install dependencies:
```bash
go mod download
```

2. Create `.env` file and run:
```bash
go run main.go
```
